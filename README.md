## CN2 GIA 的实际表现：第三方测评给出的数字

线路名字听起来抽象，落到体感上就是三个指标：延迟、丢包、晚高峰是否掉速。

有第三方测评作者记录过他的测试结果：从上海连 DMIT 的美国节点平均约 145ms，北京约 160ms；用 smokeping 连续监控三周，丢包率基本维持在 0.1% 以下；晚上 8 点到 11 点这段国内出口最拥堵的时间，延迟没有明显跳升。这是他自述的测试数据，不是本文实测，你的实际数值会随本地运营商、接入方式和时段变化，但 145–160ms 这个量级可以作为预期参考。

另一篇测评把它的特点概括为虚拟化、不超售、支持支付宝。对国内用户来说，后两点最实际。

**不超售**意味着你买的 CPU 和内存不会被同一台物理机上的其他用户分走。低价 VPS 常见的毛病是白天正常、晚上集体卡，原因就是物理机上的虚拟机开得太多，高峰期大家一起抢 IO 和带宽。不超售的代价是单价高，好处是性能曲线平。

**支持支付宝**省掉了虚拟卡和代购的环节，续费也不会因为支付方式出问题而断掉。

带宽上限保守是这套方案的另一面。定位最高的系列给的是 1Gbps 端口，配 500GB 到 2TB 的月流量额度，跑建站、代理、数据中转这类中低带宽、要求稳定的场景刚好；拿它做视频分发、大文件下载站、跑满带宽的持续传输，流量和带宽两头都不够用。第三方测评里也提到这一点，把它归在建站和代理的适用范围内。

## 不选 DMIT 也合理的三种情况

有三种需求，DMIT 的产品结构本身就不对口，硬推没有意义。

**第一种：只要便宜，能跑起来就行。**
低价年付档的真实价格是这样的：国际线路的入门款年付 $28、标准款 $40，折合月均两美元出头；走三网优化（GIA + AS9929 + CMIN2）的版本年付约 $66 和 $98；主打双 ISP 属性的产品线年付约 $52 和 $58，100Mbps 带宽，明确说明中国到洛杉矶方向的路由不做优化以维持 ISP 属性，IP 有时还会被错误地理定位到中国大陆。这类商家的折扣常做成循环的，用码后国际线入门款 $14/年，第二年续费仍是这个价，不是首年特价那种套路。个人博客、静态页面、跑个定时任务，这一档完全够，没必要为用不上的线路付钱。

**第二种：要的是双 ISP 住宅 IP 做跨境电商或账号运营。**
这类需求的核心是 IP 段来自真实民用宽带运营商，平台风控识别不出是 VPS。DMIT 公开的产品信息里没有这类 IP 产品，它的定位在线路优化和资源不超售，不在 IP 属性。做 TikTok、亚马逊多账号、需要干净住宅 IP 的，要去找专门做原生 IP 和双 ISP 的商家，别在优化线路上绕。

**第三种：要独享整机、大带宽、大内存。**
独立服务器是另一个品类。SpinServers 的达拉斯机房：E3-1280 v5 四核 / 32GB / 1TB NVMe / 10Gbps 端口 @30TB 流量 $49/月；2×E5-2630L v3 十六核三十二线程 / 256GB / 2×1.6TB SSD / 10Gbps @30TB $89/月；EPYC 7702P 六十四核 / 512GB（可升 1TB）/ 240GB + 7.84TB NVMe / 10Gbps @100TB $449/月。圣何塞机房有 2×E5-2630L v3 / 64GB / 1.6TB SSD / 500Mbps 不限流 $79/月，以及 256GB 内存 / 1Gbps 不限流 $99/月。两地默认 10Gbps 端口，支持支付宝和微信，多数套餐 30 分钟内自动开通。

它的线路不是 CN2 GIA。测评作者实测达拉斯机房：电信去程经圣何塞、回程直连，延迟约 180ms；联通回程走 AS4837；移动去程经洛杉矶、约 200ms，回程直连。比我上面说的 DMIT 那组数字高 20–55ms，晚高峰能不能扛住取决于你的用途。要独享资源、要大内存、要不限流量，这个延迟可以接受；要国内访问像本地一样跟手，它做不到。

高防是另一条岔路。有服务商把 DDoS 防护做成所有方案的默认配置，并提供更高防护等级的升级选项，靠自研系统实时监控和自动清洗。具体防护规格和价格需要以官网当期页面为准。如果你的站已经在被打，线路优化的优先级要往后放，先解决清洗能力。

## 下单前要问清的四个问题

这四个问题比套餐名重要，前排的推荐文很少讲透。

**一、续费价是多少，折扣是不是循环的。**
DMIT 全系是月付标价，没有“首年特价”这种结构，续费价和首购价一致，这一项在它身上不构成风险。换成任何一家做年付促销的商家，都要问清楚：优惠码是只限首单，还是每次续费都生效。循环折扣和首单折扣，三年下来差一倍。

**二、退款条件是什么。**
按可查到的条款摘要，DMIT 的规则是：新购 3 天内且流量使用不超过 30GB，可全额退款，扣除支付网关收取的交易手续费；新购 30 天内可按剩余流量和时长核算部分退款；续费订单、余额支付、滥用、网络或 IP 地区问题不予退款；同一系列产品已退款 3 次的也不再受理。IP 不可用的情况需要在购买当日联系客服。买之前把这几个时间点记下来，比事后争论有用。

**三、流量超了是停机、限速还是按量计费。**
行业里两种口径：给月流量额度（GB）的，超了可能停机或按量收费；给端口带宽（Mbps）的，超了降速但不断网。DMIT 给的是月流量额度，比如洛杉矶 TINY 档 1TB。超额后的具体处理方式在其套餐页上没有明确写出，下单前用工单问一句，比事后猜安全。

顺带说一个能省钱的活动：DMIT 目前有流量重置机制，每次重置可恢复基础流量的 20%，在产品有效期内最多免费重置 2 次，通过控制面板自行操作。这个活动标注到 2026 年 12 月 31 日结束。买 TINY 这种小流量档的人，两次重置相当于多出 40% 的流量额度。

**四、IP 能不能换，代价多大。**
条款摘要显示，Eyeball 网络在实例购买满 7 天、距上次换 IP 满 15 天、ICMP 和所有 TCP 端口都被屏蔽、剩余服务时长不少于 7 天的情况下可以免费更换；其余情况和其他网络等级是 $5/次，需要满足购买满 24 小时、剩余时长足够等条件。IP 由系统随机分配，不指定地区和段，换完不可撤销、不退款。做建站和账号类业务的，这一条要提前看清楚。
